# 📌 GitHub User Details

A lightweight web application that allows you to **fetch and display GitHub user profiles**.  
Enter a GitHub username, and instantly see the user’s details like profile picture, bio, repositories, followers, and more.

👉 **Live Demo:** [GitHub User Details](https://itslokeshx.github.io/Github_user_details/)

---

## ⚡ Features
- Search any GitHub username and get profile information
- Displays:
  - Profile picture
  - Bio
  - Public repositories
  - Followers & following
  - Link to GitHub profile
- Responsive and lightweight design
- Built with vanilla JavaScript, HTML, and CSS

---

## 🛠️ Tech Stack
- **HTML5** – Structure
- **CSS3** – Styling
- **JavaScript (Vanilla)** – API fetching and DOM manipulation
- **GitHub API** – Fetch user data

---

## 🎯 How It Works
1. Enter a GitHub username in the search box.
2. Click **Search**.
3. Profile data is fetched from the GitHub API and displayed instantly.
